# Aura Detector 2.0

A simple and interactive web application that calculates a user's Aura Score based on their answers to a set of questions.

## 🌐 About the Project

Aura Detector 2.0 is a single-page web application developed using HTML, CSS, and JavaScript.

The website presents users with a series of questions and calculates a score based on their responses. The final score is converted into an Aura Level and displayed to the user in an interactive and easy-to-understand format.

## ✨ Features

- 🧠 Interactive question-based quiz
- 📊 Dynamic Aura Score calculation
- 🔮 Different Aura Levels based on the final score
- ⚡ Instant results using JavaScript
- 🎨 Clean and responsive user interface
- 📱 Works on desktop and mobile screens
- 🖼️ Custom assets and branding
- 🔄 Easy quiz interaction and navigation

## 🔮 Aura Levels

| Score | Aura Level |
|------:|------------|

| 60–69 | 😎 Cool Aura |
| 70–79 | 🔥 Pro Aura |
| 80–89 | 🗿 Savage Aura |
